# Collaboration guide

## Roles

- **Source researchers:** verify publisher links, licences, denominators and update notes.
- **Data researchers:** define fields, periods, units and reproducible transformations.
- **QA reviewers:** reproduce claims, test edge cases and protect unknown states.
- **Policy analysts:** frame answerable questions and separate evidence from interpretation.
- **Visualisers:** make accessible charts with honest scales, labels and alt text.

One person can hold several roles, but evidence-changing pull requests should get a second-person review. Small, bounded pull requests are preferred. WhatsApp can coordinate interest, but decisions and evidence belong in public issues or pull requests so they remain inspectable. Do not copy private chat content into the repository without consent.

Use issues for a question, source list and acceptance criteria; use pull requests for evidence and tests. Disagreement should be resolved by tightening the claim, improving the source or labelling uncertainty—not by averaging political views.
