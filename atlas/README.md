# Evidence atlas

`index.html` is a self-contained static view generated from the sanitised public catalogue and roadmap. It contains no private paths, source storage identifiers, operational host details or source bodies. Open it directly or serve the repository with `python3 -m http.server 8000`.

The UI labels the snapshot date and keeps the 24 held products separate from the 52-lane roadmap. Publisher links open in a new tab with `noopener noreferrer`.
